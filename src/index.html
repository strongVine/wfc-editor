Симметрия по §7. Биты идут 3 2 1 0 слева направо.
Файл не открыт
Кликай по битам в нибле — зеркальный бит проставится автоматически. Ctrl+S — сохранить.
Нажми «Открыть…» чтобы загрузить файл матрицы.
Файлы не открыты
Верхняя матрица редактирует строку Down своих состояний (что под ней). Нижняя — строку Up (что над ней). Ctrl+S — сохранить грязные.
Открой верхний и нижний файлы матриц.
Файл не открыт
Кликай по тайлам в боковых ячейках — соединение и его зеркальный бит проставятся атомарно. Серый = выкл, цветной = вкл. Повороты — реальные (CSS rotate r·90°). Ctrl+S — сохранить.
Открой файл во вкладке «Горизонталь».
Файлы не открыты
Выбери слой-центр (↑ верх / ↓ низ) и состояние в нём; на противоположной стороне рисуются парные плитки в 4 поворотах. Клик по повороту переключает соединение — зеркальный бит в парном слое проставляется атомарно. Ctrl+S — сохранить грязные слои.
Открой оба файла во вкладке «Вертикаль».
